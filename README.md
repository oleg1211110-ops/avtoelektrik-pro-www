# avtoelektrik-pro.kz — сайт АвтоЭлектрик PRO (готовая сборка, статика)

**Что за сайт.** АвтоЭлектрик PRO — сайт автоэлектрика в Алматы (услуги, случаи из практики, блог), переехал с Tilda на нашу статику
по тем же рельсам, что и pdd-pro.kz. Домен — avtoelektrik-pro.kz; язык — русский; **статус — запущен**. Владелец — Олег Дмитриев.

**Стек.** Статический HTML. PHP, Node и база данных не нужны. Внешних скриптов, шрифтов, CDN нет; небольшой CSS — внутри страниц.
Счётчики (Google Tag Manager/Analytics, Яндекс Метрика) включаются в сборке только на боевом домене (в предпросмотре их нет).

**Сборка.** На сервере не нужна. Сайт собирается в закрытом репозитории Олега (`tools/tilda_static.py` из `content.json`,
выкладка сюда — `tools/tilda_static_publish.py`) и коммитится **уже собранным** в `site/`. Здесь руками ничего не править — перезаписывается.
Служебное (не выкладывать): `README.md`, `SOURCE` (из какой версии контента собрано), `redirects-nginx.conf` (см. ниже).

**Что отдаёт веб-сервер — папку `site/` как корень сайта:**
- `site/index.html` — главная; страницы услуг — папки с `index.html` (`/kompyuternaya-diagnostika-avto-v-almaty/` и т. д.);
- статьи блога — `/novosti-i-rekomendatsii/<slug>/`;
- `site/404.html` — «страница не найдена»; `site/sitemap.xml`, `site/robots.txt`;
- значки `favicon.ico`, `favicon.svg`, `apple-touch-icon.png` (180×180), картинка для соцсетей `og.png` (1200×630).
  Ссылки на них — с `?v=<хеш>`, долгий кэш не мешает. CSS — внутри HTML, отдельных файлов нет.

**301-редиректы со старых адресов Tilda.** Файл `redirects-nginx.conf` (в корне репозитория, НЕ в `site/`). Подключить в блоке
`server { … }` сайта выше `location /`:  `include /путь/redirects-nginx.conf;`  Проверка и применение: `nginx -t && systemctl reload nginx`.
Внутри `site/` есть ещё `_redirects` (формат GitHub Pages/Netlify) — на случай выкладки туда; для nginx он не нужен.
Большинство адресов страниц совпадает с Tilda (переносим один в один) — 301 нужны в основном для служебных адресов `/tpost/…` и `/pageNNN.html`.

**База, запись файлов, cron, почта, формы, внешние сервисы** — нет. Заявки — кнопки «Позвонить» и «Написать в WhatsApp».

**Ветки.** `main` — всегда готовая версия. Файл `SOURCE` — из какой версии контента собрано.

**Предпросмотр.** Пока идёт предпросмотр, все страницы `noindex,follow`, в `robots.txt` — `Disallow: /`. Запуск — по слову Сергея/Олега:
сборка без предпросмотра (`site_preview: false` в карточке), noindex уходит, `robots.txt` — `Allow: /` и `Sitemap: https://avtoelektrik-pro.kz/sitemap.xml`.

**При обновлении** нужно только заменить файлы из `site/` (и `redirects-nginx.conf`, если менялись редиректы). Что-то ещё понадобится —
будет в сообщении к версии.
