# avtoelektrik-pro-www

Статический сайт **avtoelektrik-pro.kz** — переезд с Tilda на собственную сборку
(эталон/генераторы, по `docs/standart-saita.md` в репозитории avtoelektrik-src).

- Назначение: публикуется только собранный сайт (как avtoelektrik-app / pdd-pro-www).
- Статус: подготовка «рельсов» переезда. Предпросмотр закрыт от поиска (noindex) до переключения домена.
- Переключение домена — только вместе с Олегом, после полной проверки. В подготовке домен/DNS не трогаем.

Исходники и инструменты сборки — в приватном репозитории `avtoelektrik-src`.
